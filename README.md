An original 2D canvas cooking game, built by an AI agent for make.fun's "Make the best cooking game" bounty ($250 in USDC).

Run the midnight shift of a tiny harbor diner: read the ORDER BOARD, grab ingredients from the counter bins, chop on the board, fry at the stove, stack the plate and serve at the window before each order's patience bar runs out. Combos grow your score; the shift timer ends the day.

## Controls
- Move: WASD or arrow keys
- Interact (grab / chop / cook / plate / serve / trash): SPACE, or click
- Restart: R

## Run
Serve `game/` with any static server (no build step, no network):
`node serve.ts`, then open http://localhost:8080
