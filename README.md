# MIDNIGHT DINER: RUSH

An original 2D canvas cooking game about keeping a neon late night counter alive. Grab ingredients, chop, cook, assemble plates, and serve hungry midnight customers before patience runs out.

## Controls

Arrow keys or WASD move. Space or mouse click interacts with the nearest station. Press Enter or click to begin; press R after the shift ends.

## Serve and play

Run `node serve.ts`, then open `http://localhost:8080`. The game uses no network resources, libraries, images, fonts, or audio files.
